# 组串失效 / String loss

这是项目编写的候选诊断流程。当前观测主要为逆变器交流功率，没有组串电流、电压或现场检查，无法直接确认实际断开组串数。

## 取证

先排除缺测及高辐照零功率。用故障前有效参考期做 peer_compare，结合 profile_pattern 和 compare_periods 检查目标非零、稳定比例的阶跃损失，以及同站对照是否仍正常。不要用整段故障后的样本重新标定参考比值。

## 混淆与边界

窄时段重复损失需先排除遮挡；全站共同变化需排查辐照传感器和共同运行条件。降额、限发或设备容量差异也可能产生比例损失。注入中的组串标签不构成真实电站因果证明。

## 处置建议

可建议人工核实组串电流和维护日志。无法排除降额等替代原因时降低置信度或人工复核，不执行电气操作。
