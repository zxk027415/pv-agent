# 辐照传感器漂移 / Irradiance sensor drift

这是项目编写的候选诊断流程。参考 pvlib-pvwatts-dc、pvlib-pvwatts-ac 和 pvlib-faiman 的模型输入与假设，不能从知识文档推定本站设备参数。

## 取证

先检查 POA 测点的数据质量。peer_compare 核对可见逆变器间的相对关系是否稳定；使用同一套有出处的额定功率及温度参数做故障前后 expected_power，对比多日共同性能下降。工具返回 unavailable 时不具备物理支持，不能用知识库中的典型参数替代。

## 混淆与边界

同站比值稳定不能排除共模异常。温度模型偏差、积灰、限发或真实全站退化也可能造成物理性能偏差；静态低性能比不等于传感器渐变漂移。需要独立辐照参考、校准或维护记录才能进一步确认真实根因。

## 处置建议

故障候选定位到 POA 传感器，不能定位到任意逆变器。可建议人工比对独立辐照与校准记录；缺少独立支持时返回无法判断或人工复核。
